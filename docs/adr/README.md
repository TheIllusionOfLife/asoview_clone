# Architecture Decision Records

This directory holds Architecture Decision Records (ADRs) for significant design choices that affect the repo over time.

Format: lightweight [MADR](https://adr.github.io/madr/) — one file per decision, numbered sequentially, named `NNN-kebab-case-title.md`.

Each ADR should cover:

- **Status** (Proposed / Accepted / Superseded)
- **Context** (what forced the decision)
- **Decision** (the choice, stated in one sentence where possible)
- **Consequences** (what becomes easier, what becomes harder, what follow-ups exist)
